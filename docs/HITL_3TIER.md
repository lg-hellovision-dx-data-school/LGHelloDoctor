# LG HelloDoctor — HITL 3-Tier 운영 가이드

본 문서는 **누가·언제·무엇을** 검수하는지의 *운영 매뉴얼* 입니다.
거버넌스의 *왜* 와 *원칙* 은 [`CLEAN_ARCHITECTURE_GOVERNANCE.md`](./CLEAN_ARCHITECTURE_GOVERNANCE.md) 참조.

## ① 도메인 자문단 (4 역할)

### 1-A. 의사 (응급의학·일반의)

| 항목 | 내용 |
|---|---|
| 책임 영역 | `EMERGENCY_KEYWORDS` · `EMERGENCY_SCORES` · `MEDICAL_CORRECTIONS` · RAG 출처(KDCA) · 진료과 매칭 · 답변 안전성 샘플 |
| 검수 주기 | 분기 1회 정기 + 사고/누락 발견 시 즉시 |
| 검수 산출물 | 키워드 추가/삭제 의견서 · 답변 샘플 안전성 평가 |
| MVP 단계 | 미배치 — KDCA 공공자료 + 개발자 검토로 갈음 |
| 정식 출시 전 | 응급의학과 1명 + 가정의학·내과 1명 (총 2명 권장) 자문 위촉 |

### 1-B. 약사

| 항목 | 내용 |
|---|---|
| 책임 영역 | `medication_inquiry` 의도 답변 · 약물 상호작용 · OTC 안내 · 부작용 정보 |
| 검수 주기 | 출시 전 1회 + 분기 1회 + 식약처 안전성 정보 갱신 시 |
| 검수 산출물 | 약물 답변 샘플 30~50건 검수 의견서 |
| MVP 단계 | 미배치 — 의약품 안전사용서비스(DUR) 가이드 우선 인용 |
| 정식 출시 전 | 임상약사 1명 자문 위촉 |

### 1-C. 노년학·시니어 UX

| 항목 | 내용 |
|---|---|
| 책임 영역 | 어휘 난이도 · 권유형 어조 · 음성 속도 · 글자 크기 · 호출어 · 답변 길이 |
| 검수 주기 | 출시 전 1회 + 월 1회 답변 샘플 + UI 변경 시 |
| 검수 산출물 | 시니어 친화 점검 체크리스트 결과 |
| MVP 단계 | 한국어 비율 40% · 1~3문장 임계값 + `test_한국어_중심_응답` 으로 자동 검증 |
| 정식 출시 전 | 노년학 전문가 또는 시니어 UX 전문 디자이너 1명 자문 |

### 1-D. 법률·컴플라이언스

| 항목 | 내용 |
|---|---|
| 책임 영역 | `FORBIDDEN_WORDS` · 의료법 제27조 · 의료광고법 · 개인정보보호법 · 면책조항 |
| 검수 주기 | 출시 전 1회 + 분기 1회 + 의료법 개정 시 |
| 검수 산출물 | 의료법 위반 가능성 평가서 · 면책조항 초안 검토 |
| MVP 단계 | 미배치 — `FORBIDDEN_WORDS` 10개 + 면책 디스클레이머로 갈음 |
| 정식 출시 전 | 의료/IT 전문 변호사 1명 자문 위촉 |

## 트리거 → 자문 → 머지 흐름

```
[ 코드 변경 발생 ]
      ↓
[ .claude/settings.json PreToolUse 훅 ]
      ↓ FORBIDDEN_*/EMERGENCY_*/MEDICAL_CORRECTIONS 패턴 감지 → 경고 출력
[ PR 작성 ]
      ↓
[ PULL_REQUEST_TEMPLATE.md HITL 체크리스트 ]
      ↓ 해당 자문 영역 체크 + 검토 결과 명시
[ /test 통과 ]
      ↓ 회귀 차단 (응급 100%, 금지어 0건)
[ 자문 검토 결과 첨부 ]  ← 의사·약사·노년학·법률 중 해당자
      ↓
[ /validate 7항목 점검 ]
      ↓
[ 머지 → 배포 ]
```

## 자주 묻는 질문

**Q. 자문단이 모두 위촉되기 전엔 출시할 수 없나요?**
A. 출시 가능합니다. MVP 는 KDCA 공공자료 + 자동 테스트 + 면책조항으로 *최소 기준* 충족.
   다만 *"의료 자문단 미배치"* 사실을 README/면책조항에 투명하게 명시.

**Q. 자문 비용이 부담되면?**
A. 1차로는 *학회 자문 양식* (대한응급의학회·대한약사회 등) 이용. 2차로 *유료 자문 위촉*.

**Q. AI 가 자문단을 대체할 수 있나요?**
A. **불가**. AI Judge (LangSmith Faithfulness/Safety) 는 *검증 도구* 일 뿐, 책임은 사람이 짐.
   AI 단독 결정 = 의료법 위반 책임 소재 불명. → 본 거버넌스의 핵심 대전제.

**Q. 자문 의견이 충돌하면?**
A. 우선순위: **법률 > 의사(응급의학) > 의사(일반의) = 약사 > 노년학·UX**.
   안전·법적 책임이 사용성보다 우선.
