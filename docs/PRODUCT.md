# LG HelloDoctor — 제품 정의서

## 제품 개요
**LG HelloDoctor**는 시니어(어르신) 대상 음성 의료 AI 서비스입니다.
TV 또는 모바일 기기에서 "헬로비"를 호출하면 AI가 음성으로 증상을 듣고,
주변 병원 안내와 의료 정보를 제공합니다.

## 핵심 사용자
- **주 사용자**: 65세 이상 시니어 (디지털 리터러시 낮음)
- **보조 사용자**: 시니어의 가족 (서비스 설정 및 관리)

## 핵심 가치
1. **접근성** — 음성 인터페이스로 터치 없이도 사용 가능
2. **안전성** — 응급 상황 즉시 감지 및 119 안내
3. **신뢰성** — 의료법 준수, 과도한 진단 표현 금지
4. **친근함** — "헬로비" 캐릭터를 통한 따뜻한 응대

## 주요 기능

### 1. 음성 증상 상담
- 호출어 "헬로비" 감지 → 마이크 활성화
- 음성 → 텍스트 변환 (Whisper STT)
- 증상 분석 및 진료과 안내

### 2. 주변 병원 검색
- GPS 기반 반경 3km 이내 병원 검색
- 거리, 전화번호, 지도 링크 제공

### 3. 응급 상황 감지
- 위험 키워드 자동 감지 (HIGH/MEDIUM/LOW 등급)
- HIGH 등급 시 즉시 119 전화 안내

### 4. 의료 정보 제공
- RAG 기반 의료 지식 검색 (132개 문서)
- 복약 정보 안내

## 기술 스택
| 영역 | 기술 |
|------|------|
| 프론트엔드 | React 19, TypeScript, Vite, nginx |
| 백엔드 | FastAPI, Python 3.11 |
| LLM | Groq API (llama-3.3-70b-versatile) |
| STT | OpenAI Whisper |
| VAD | Silero VAD |
| 벡터DB | ChromaDB 1.5.5 |
| 임베딩 | ko-sroberta-multitask |
| 병원검색 | Kakao Map API |
| TTS | gTTS |
| 배포 | Docker Compose |

## 제약사항
- 의료 진단 행위 금지 (의료법 준수)
- 처방전, 투약, 확정 진단 표현 금지 (`FORBIDDEN_WORDS`)
- 시니어 대상 → 어려운 의학 용어 사용 금지
- 답변은 3~4문장 이내로 제한

## 서비스 화면
- **TV 모드**: `HelloBeeTvScreen` — 대형 화면 최적화
- **모바일 모드**: `MedicalChatScreen` — 채팅 인터페이스
