## 파이프라인 처리 흐름

```
사용자 (음성 입력 — "헬로비 호출")
    │
    ▼ ① 입력
  STT — Whisper → 음성 → 텍스트
    │
    ▼ ② STT
  응급 키워드 감지
  (쓰러짐·식은땀·한쪽 마비·말이 어눌 등)
    ├─ 감지됨 ──────────────► 응급 안내 메시지
    │
    ▼ ③ 응급 감지 (미감지)
  LLM 의도 분류
  (병원 검색 / 약 정보 / 증상 질문)
    ├─ 병원 검색 ──► 카카오 Local API → 위치 기반 탐색
    │
    ▼ ④ 의도 분류 (약정보·증상)
  RAG — 건강보험심사평가원 데이터
    │
    ▼ ⑤ 처리
  LLM 응답 생성 (반복 대화 가능)
    │
    ▼ ⑥ 출력
  텍스트 응답 — 화면 출력
```

**서비스 적용 환경**
- 학습 환경: NVIDIA A100 GPU 기반 학습 및 평가
- 배포 고려 구조: Docker 기반 STT · LLM · RAG 통합 파이프라인 구성
- 경량화 포인트: VAD 전처리, LoRA, 4bit 양자화, 경량 벡터 DB 적용

## STT 고도화

| 항목 | 내용 |
|------|------|
| **모델** | Whisper-large-v3 + LoRA |
| **데이터** | AI Hub 한국인 노인 음성 7,000개 |
| **선택 이유** | 사전학습 모델 기반 노인 음성 도메인 적합 |
| **고도화 방법** | Silero-VAD 기반 무음 제거, 간투어 정제 |

**성과**
- CER (문자 오류율): **3.4% → 2.9%**
- WER (단어 오류율): **14.2% → 12.9%**

## LLM 고도화

| 항목 | 내용 |
|------|------|
| **모델** | Llama-3.2-3B + LoRA |
| **데이터** | 서울아산병원 진료과표 기반 8,800개 |
| **선택 이유** | 경량 모델 기반 의료 도메인 적합 |
| **고도화 방법** | 응급 키워드 30개 확장, 3턴 문진 |

**성과**
- 의도 분류: **57.0% → 94.9%**
- 응급 감지: **59.5% → 90.0%**

## RAG 고도화
