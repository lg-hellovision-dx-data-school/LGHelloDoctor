## 주요 기능

### 1. 음성 증상 접수
노인 음성 특성을 고려한 발화를 인식해 복잡한 타이핑 없이 사용 가능

### 2. 진료과 매핑
18개 증상군 분류 및 3턴 문진을 통해 사용자 증상을 좁혀 적절한 진료과 연결

### 3. 위치 기반 병원 안내
Kakao Local API를 사용해 추천 진료과에 맞는 주변 병원의 상세 정보 제공

### 4. 응급 안전망 ⚠️
30개 이상의 응급 키워드 감지 시 일반 응답을 중단하고 응급 안내 우선 반환

---

## 안전 설계 (의료 리스크 최소화)

- 질병 **진단·처방은 수행하지 않고**, 진료과 추천과 병원 안내만 수행
- 응급 키워드 감지 시 일반 답변 생성을 중단하고 응급 안내 우선 반환
- 질병명 단정 표현을 출력하지 않도록 프롬프트 및 후처리 규칙 적용
- 모든 의료 응답은 참고용 안내이며 최종 판단은 의료진 상담 필요 명시

## 핵심 성과

### 의도 분류 정확도: 57.0% → 94.9% (+37.9%p)
> temperature=0 설정, 역할/예시/출력 형식 기반 프롬프트 재작성, 3턴 문진 로직 적용으로 의도 분류 일관성 강화

### 응급 감지율: 59.5% → 90.0% (+30.5%p)
> 경계 발화 반영, 응급 키워드 확장, 재검증 로직 추가

### RAG 검색 정확도(Top-3): 39.7% → 62.1% (+22.4%p)
> 벡터 검색 결과와 키워드 검색 결과를 함께 반영하는 Hybrid Search 적용
